# SYS-CONF USB IRX (BDM Assault)

`USBD.IRX` and `USBHDFSD.IRX` here are **BDM Assault** (exFAT), fetched by `tools/bootstrap-installer-vendor.sh` from [BDMAssault v1.0.0](https://github.com/israpps/BDMAssault/releases/tag/v1.0.0).

The FunTuna installer writes them to `mc?:/SYS-CONF/` (PS2SDK FAT drivers stay in `mc?:/BOOT/`).

Not committed — see root `.gitignore`.
